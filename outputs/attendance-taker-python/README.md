# Attendance Taker Python App

This is a futuristic desktop attendance taker made with Python and Tkinter.

## Features

- Add, edit, and delete people
- Mark people as Present or Absent
- Live present and absent counts
- Real-time neon-style graphic chart
- Dark modern dashboard interface
- Save attendance sessions
- Open previous saved sessions
- Export attendance as CSV
- No authentication system

## Run In VS Code

1. Open VS Code.
2. Click **File > Open Folder**.
3. Select this folder:

```text
C:\Users\hp\Documents\Codex\2026-06-03\refine-the-prompt-and-make-an\outputs\attendance-taker-python
```

4. Open `attendance_taker.py`.
5. Click the Run button.

You can also run it from the VS Code terminal:

```text
python attendance_taker.py
```

If `python` does not work, install Python from `python.org` and install the Python extension in VS Code.

## Files

- `attendance_taker.py` - main app
- `attendance_data.json` - created automatically when you save data
- exported CSV files - created wherever you choose during export

## Push To GitHub From VS Code

1. Open this project folder in VS Code.
2. Open the Source Control tab.
3. Click **Initialize Repository** if VS Code asks.
4. Click the plus button to stage all files.
5. Type a commit message:

```text
Initial attendance taker app
```

6. Click **Commit**.
7. Click **Publish Branch** or **Publish to GitHub**.
8. Choose a repo name:

```text
attendance-taker-python
```

9. Choose public or private.
10. Publish it.

Note: This is a Python desktop app, so GitHub Pages will not run it as a website. GitHub will store the code. To use the app, run it on your computer with Python.
